# Pièces justificatives — à déposer ici

`../build_concern.sh` fusionne ce répertoire, trié par nom, à la suite de la lettre et du CV dans
`outputs/Alexandro_Disla_Dossier_DP-CGI1210-2026.pdf`.

L'annonce ne demande que le CV et la lettre. L'attestation part quand même, parce que le poste
exige un Bac+4 et que le CV comme la lettre y renvoient. Aucune pièce d'identité n'est demandée.

```
01_attestation_ctpea.pdf   Attestation C.T.P.E.A — copie de ../../../attestation_diplomes/
```

Le nom doit contenir `attestation` ou `ctpea` : c'est ainsi que le script vérifie sa présence.

Ce répertoire est ignoré par git (voir le `.gitignore` du dossier parent) — ne pas committer
les pièces.
